# medibot-proyecto-final

Proyecto de Fin de Curso (DAW). Aplicación innovadora que integra diversas tecnologías aprendidas a lo largo de la formación como Técnico Superior.

- Arquitectura MVC

*Proyecto Formativo - Desarrollo de Aplicaciones Web (DAW)*
