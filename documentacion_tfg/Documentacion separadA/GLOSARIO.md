# Glosario de Términos

- **API (Application Programming Interface)**: Interfaz que permite la comunicación entre diferentes aplicaciones de software.
- **API Platform**: Framework construido sobre Symfony para desarrollar APIs REST y GraphQL de forma eficiente siguiendo estándares.
- **Backend**: Parte del desarrollo web que se encarga de la lógica del servidor, base de datos y seguridad.
- **Bot**: Programa informático que efectúa tareas repetitivas a través de Internet, a menudo simulando el comportamiento humano.
- **CRUD (Create, Read, Update, Delete)**: Acrónimo de las cuatro funciones básicas de una base de datos.
- **Docker**: Plataforma que permite a los desarrolladores empaquetar aplicaciones en contenedores para asegurar que funcionen igual en cualquier entorno.
- **Frontend**: Parte de una aplicación web con la que el usuario interactúa directamente (interfaz de usuario).
- **GDPR (Reglamento General de Protección de Datos)**: Normativa europea que regula la protección de datos personales de los ciudadanos.
- **GPT-4**: Modelo de lenguaje de grandes dimensiones (LLM) desarrollado por OpenAI.
- **JSON (JavaScript Object Notation)**: Formato ligero de intercambio de datos, fácil de leer para humanos y máquinas.
- **n8n**: Herramienta de automatización de flujos de trabajo basada en nodos.
- **ORM (Object-Relational Mapping)**: Técnica de programación para convertir datos entre sistemas de tipo incompatibles usando lenguajes orientados a objetos.
- **React**: Biblioteca de JavaScript para construir interfaces de usuario basada en componentes.
- **SPA (Single Page Application)**: Aplicación web que carga una sola página HTML y actualiza dinámicamente el contenido a medida que el usuario interactúa con ella.
- **Symfony**: Framework de PHP diseñado para optimizar el desarrollo de aplicaciones web de alto rendimiento.
- **Webhook**: Método para que una aplicación proporcione información en tiempo real a otras aplicaciones.
